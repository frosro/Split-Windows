## UpDownSplit 分屏软件全面优化方案

单文件 C# WinForms 托盘程序（`UpDownSplit.cs`，945 行）。保持单文件架构与系统 csc 编译方式不变，所有改动在 `UpDownSplit.cs` 内完成。

### 第 0 步：git 基线
- `git init` + `.gitignore`（忽略 `UpDownSplit.exe`），提交当前源码作为基线，优化完成后再提交一次。

### A. 正确性 / 稳定性修复
1. **如实反馈分屏结果**（`UpDownSplit.cs:308-322, 70-92, 703`）
   - `Place` 返回 bool（窗口失效时 false）；`SplitWindows` 找不到第二个窗口时仍贴第一个窗口（保留现有行为）但返回 false；
   - CLI `top/bottom/split` 按实际结果返回退出码 0/1；
   - 托盘"一键分屏"在未找到第二个窗口时气泡提示"已贴上半屏，同屏未找到第二个窗口"；
   - `Apply()` 统计实际摆放数量并提示被跳过的窗口（扫描后到确认前被关闭的），消息不再虚报。
2. **消除固定 `Thread.Sleep(30)` 与贴靠竞态**（`UpDownSplit.cs:360`）
   - 还原最大化/最小化后：轮询等待还原状态生效（有界 ~150ms，通常立即通过）→ `SetWindowPos` → 用 DWM 可见边框校验，偏差过大重试 1~2 次；
   - GUI 模式追加一次性 WinForms Timer 延迟校验（~150ms）纠正迟到的动画覆盖（非阻塞，不再冻结 UI）；CLI 模式仅用同步有界重试；
   - `RestoreLast`（`:324`）应用同样处理。
3. **资源泄漏**
   - `MakeIcon`（`:910`）：P/Invoke `DestroyIcon` 释放 `GetHicon` 句柄；`TrayApp` 实现 `Dispose` 释放 NotifyIcon 与图标；`SplitConfigForm` 释放 `_small` 字体（`:422`）。
4. **异常防护**："重新扫描窗口"处理器（`:481`）包进 Safe()；`Main` 挂 `Application.ThreadException`，异常改为气泡提示而非崩溃对话框。
5. **自启动自校验**（`:884-898`）：勾选状态同时校验注册表路径是否指向当前 exe，exe 移动后重新勾选即写入新路径。

### B. 性能 / 流畅度
1. **窗口枚举提速**（`:217-241`）：`ListWindows` 弃用每窗口 `Process.GetProcessById`（全表扫进程，O(窗口×进程)），改 `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` + `QueryFullProcessImageName` + pid→名称字典缓存，降为 O(窗口数)；同时消除每次设置窗口打开/重扫时的卡顿。
2. **预览防闪烁**：新增 `BufferedPanel`（DoubleBuffered=true）作预览面板，拖比例滑条不再闪烁。
3. **绘制对象缓存**：`DrawZoneNumber`（`:783`）的 Font/Brush 提为 static readonly。
4. **几何计算去重**："工作区+比例→两块区域矩形"收敛到 `WindowMover` 一处，`SplitWindows`/`Place`/`Apply`/预览共用（现有三处重复实现统一）。

### C. 体验改进
1. **配置记忆**：新增 `%APPDATA%\UpDownSplit\config.txt`（key=value 纯文本，零新依赖），按"显示器设备名+分辨率"记住每屏的布局/比例；打开设置窗口自动填入上次选择，"确定分屏"成功后保存。
2. **启动气泡只弹一次**：首次启动展示快捷键说明，之后静默启动；快捷键注册失败的警告气泡始终弹出。
3. **快捷键失败可补救**：托盘菜单新增"重新注册快捷键"项（释放占用后无需重启程序）。
4. 比例滑条范围由 30–70% 放宽到 20–80%。
5. 退出时完整清理（注销快捷键 + 释放托盘图标资源）。

### D. 工程化
1. `build.cmd` 自动探测 csc 路径（Framework64 → Framework 回退），去掉写死的 `C:\Windows\...` 绝对路径。
2. `test.ps1`：适配新退出码断言、清理遗留的 a.txt/b.txt、少量等待重试降低偶发失败。
3. `README.md`：补充配置记忆、静默启动、快捷键补救等新行为。
