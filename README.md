# 上下分屏助手 (UpDownSplit)

专为横屏 + 竖屏双显示器设计的小工具：一块屏想"上下分"不再需要 PowerToys。
无需安装，单个 exe，双击即用。

## 方式一：分屏设置窗口（推荐）

1. **双击托盘图标**（或右键托盘图标 → "分屏设置..."）打开设置窗口，顶部会显示检测到的
   所有显示器（按真实相对位置摆放，自动标注横屏/竖屏）。
2. 在每块显示器的配置卡上：
   - 选择**分屏方式**：不分屏 / 上下两分 / 左右两分（竖屏默认上下、横屏默认左右）
   - 拖动**分割比例**滑条（30%–70%），预览图中的分割线实时移动
   - 在"区域一 / 区域二"下拉框中选择要放进该区域的**当前打开的窗口**（可跨屏选择）
3. 点击**确定分屏**，所选窗口立即被摆进对应区域（最小化/最大化的窗口会先还原再摆放）。
   摆错了可点**还原本次移动**，或按 `Win+Ctrl+R`。

## 方式二：快捷键（日常快速贴靠）

| 快捷键 | 作用 |
|---|---|
| `Win+Ctrl+↑` | 当前窗口贴到**所在屏幕**的上半屏 |
| `Win+Ctrl+↓` | 当前窗口贴到**所在屏幕**的下半屏 |
| `Win+Ctrl+S` | 一键上下分屏：当前窗口放上，同屏下一个窗口放下 |
| `Win+Ctrl+R` | 还原上次移动的窗口 |

快捷键按窗口当前所在的显示器计算，横屏竖屏通用；系统自带的 `Win+←/→` 左右分屏不受影响。

## 其他

- **开机自启**：右键托盘图标 → 勾选"开机自动启动"（写入当前用户注册表，可随时取消）。
- **退出**：右键托盘图标 → 退出。
- 左右分屏仍可用系统自带 `Win+←/→`。

## 文件

- `UpDownSplit.exe` —— 主程序
- `UpDownSplit.cs` —— 全部源码（C#，单文件，可用系统自带 csc 编译）

## 已知限制

- 以**管理员权限**运行的窗口（如任务管理器）无法被普通权限的本工具移动。
- 部分特殊窗口（不接受改变大小的）只会被移动位置。
- **视频"真全屏"会占满整块屏**：这是浏览器/播放器的全屏机制（直接接管整个显示器），
  任何分屏工具（包括 PowerToys）都无法把真全屏限制在半屏里。替代做法：
  - 网页视频用"**网页全屏 / 影院模式**"（YouTube 按 `t`、B 站点"网页全屏"按钮），
    视频就只占窗口大小 = 区域大小；
  - 本地播放器（PotPlayer/VLC 等）把窗口贴到区域后直接用"适应窗口"播放，不要按全屏。
  - 退出真全屏后窗口会变回整屏大小，按一下 `Win+Ctrl+↑`（或对应区域快捷键）即可重新贴回。
